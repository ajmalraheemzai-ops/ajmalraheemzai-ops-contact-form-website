# Contact Form Website
Single-file static site. No Node.js, no install, no server.

1. Upload index.html to GitHub Pages, Netlify Drop or Cloudflare Pages (all free).
2. Open the live site and send one test message.
3. FormSubmit emails Ajmal.abdulrahimzai123@gmail.com an activation link. Click "Activate Form" once.
4. After that, every submission arrives in your inbox. Reply-To is the visitor.
